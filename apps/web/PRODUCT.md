# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

《阴阳师》玩家，读取藏宝阁账号，盘点式神、御魂并比较配置。

## Product Purpose

天真工具箱首页不显示菜单，欢迎内容在完整页面宽度内居中；进入号来后显示工作区菜单。全站共用持续挂载的账号状态，号来保留旧 Web 的账号查询、速度盘点、PVE 预览、式神技能、御魂计算器、御魂库存，并新增收藏图鉴。

## Capabilities and Constraints

- 用户确认完整迁移现有页面和核心功能，不增加独立“工具页”菜单。
- 号来子页面统一使用 `/yys-cbg-inspector/` 路由前缀，工具箱首页仍为 `/`，页面显示名称不变。
- SID 由服务端配置初始值，login_auto 返回新 SID 后在服务端内存更新，不提供浏览器 SID 输入，不公开会话秘密。
- Web 仅通过 Nest 获取业务数据，数据库仅由 API 访问。
- 最近 12 个账号的精简商品数据与套装索引持久化到浏览器 IndexedDB，不按天过期；点击本地历史直接恢复，不请求商品接口。保留旧链接记录并标明需读取一次；保存失败明确提示。历史不代表上游最新售价和库存。
- 服务端负责上游取数、边界校验和递归字段剪枝，并按渠道、区服和订单号缓存精简商品数据 24 小时；命中不访问上游。账号、式神与御魂拆解由浏览器 Worker 完成，强化阶段按需生成。再次提交链接仍可能命中缓存，最新售价和库存以藏宝阁页面为准。
- 收藏图鉴仅展示账号已拥有且分类明确的条目，支持搜索，不为分类或收藏项打开详情弹窗；账号页直接显示收藏摘要。皮肤分为典藏/臻藏、阴阳师皮肤与其他皮肤，后两类按商品详情明确的 yys/ss 分类展示，典藏目录重叠项只出现一次；皮肤图片使用保存的英雄/皮肤配对，历史恢复不依赖服务端进程状态。御灵皮肤保持隐藏，旧历史缺少分类信息时不推断归类。头像框与其他皮肤每页显示 24 项，翻页或搜索/切换分类时重置页码。其余收藏按ID去重。高级徽章、头像框等依赖账号实际ID，未知保持横线，不冒充零；特殊皮肤 / 碎片、特殊皮肤Ⅱ、成就、术印不进入可见分类与摘要。旧历史需重读商品补齐收藏。
- 式神基础面板优先数据库，官方配置只更新身份；未知面板保留缺失提示，不能伪造面板。官方配置与目录持久化到数据库，重启可恢复。
- 支持亮暗色、移动浏览器、键盘操作与可见焦点。
- 开发期间只能后台控制浏览器，不能激活窗口或打断用户游戏。

## Brand Commitments

- 天真工具箱是全站共用工作区；欢迎内容作为菜单中的首页；号来是工具名，Phoenix 后缀仅属于号来。
- 遵循仓库约定的简约偏蓝色工作台风格，沿用现有品牌图像和共享组件，不迁入旧站 Ant Design/SCSS。
- 样式可以调整，保留旧版的信息内容、分组、图标与操作：常用数据、六位速度证据和计算条件直接显示，式神与御魂继续用图形选择弹窗，御魂强化记录从详情入口查看。
